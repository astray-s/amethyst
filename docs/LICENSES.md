# Licensing guide

Amethyst uses a split license so code can be reused broadly while project artwork keeps clear attribution.

## Source code and documentation

Code and documentation are licensed under Apache-2.0. The full terms are in [LICENSE](../LICENSE).

Apache-2.0 includes a patent grant from contributors and requires preservation of relevant license and notice text when the work is redistributed.

## Original artwork

Original Amethyst artwork listed in [ASSET_PROVENANCE.md](../ASSET_PROVENANCE.md) is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Redistributors must give appropriate credit, link to the license, and indicate if changes were made.

## Contributions

Code and documentation contributions are accepted under Apache-2.0. Original artwork contributions are accepted under CC BY 4.0 and need a provenance entry.

Do not submit material copied or extracted from another application, brand kit, screenshot set, font bundle, gem collection, icon library, or design export without a license that permits redistribution and modification.

## Dependencies

Packages installed through npm and Gradle keep their own licenses. They are not covered by the project's Apache-2.0 grant. Before release, generate an SBOM and review dependency license obligations.

## Names and trademarks

Open-source licenses do not grant trademark rights. The Amethyst name and artwork must not be used to imply endorsement by the project maintainers. Other product names belong to their respective owners.
