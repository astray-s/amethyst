# Amethyst gem generation record

The six milestone gems were generated on September 15, 2026 through OpenAI
image generation using an existing Codex access entitlement. Each request
produced one PNG. No source image, screenshot, logo, or third-party artwork was
provided as a reference.

All six prompts shared these requirements:

> Create one completely original high-resolution 1:1 PNG collectible gemstone
> asset for an Android focus app named Amethyst. Center it as an isolated
> floating object on a transparent background, with a very soft lavender glow
> and understated shadow only. Use a premium photorealistic 3D render, a deep
> violet, plum, lilac, and midnight-blue palette, a crisp silhouette, generous
> empty padding, and a form that remains readable at small icon size. Include
> no text, logo, frame, pedestal, environment, or rainbow iridescent treatment. Do
> not imitate or reference any existing app artwork, logo, gem silhouette, or
> composition. Output the largest available square resolution with transparent
> alpha.

The individual subjects were:

| File | Subject direction |
| --- | --- |
| `amethyst-cluster.png` | An asymmetrical six-point cave-grown cluster with sharp violet facets and translucent lilac depth |
| `amethyst-banded-stone.png` | A smooth oval stone with concentric lavender bands, a glassy surface, and a small irregular notch |
| `amethyst-helix.png` | A twisted helix-like shard with flowing faceted ridges and a dynamic asymmetric profile |
| `amethyst-star.png` | A compact rounded dodecahedral crystal with an internal lavender starburst and an irregular hand-cut silhouette |
| `amethyst-geode.png` | A rough asymmetrical dark geode shell opening into a luminous violet crystalline cavity |
| `amethyst-prism.png` | A tall futuristic prism with a split crown, tapered base, and offset asymmetric planes |

The generated files are 1254×1254 RGBA PNGs. Maintainers visually checked each
asset for isolation, transparency, silhouette, palette, and the absence of
logos or text before adding it to the project.
