# Amethyst brand lock

The homepage is the sole source of truth for Amethyst's visual brand.

Start with [`docs/brand/AMETHYST_HOMEPAGE_BRAND_SYSTEM.md`](docs/brand/AMETHYST_HOMEPAGE_BRAND_SYSTEM.md), then inspect the approved screenshot in [`docs/brand/reference/homepage-approved-2026-09-15.png`](docs/brand/reference/homepage-approved-2026-09-15.png).

The canonical runtime implementation is [`src/screens/HomeScreen.brand.css`](src/screens/HomeScreen.brand.css). Its cave image, gem image, palette, glow treatment, card treatment, and spacing establish the brand for future work.
